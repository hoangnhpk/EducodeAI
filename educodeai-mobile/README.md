# EduCodeAI Mobile

Ứng dụng Expo/React Native dành riêng cho học viên EduCodeAI.

## Cấu trúc source

- `src/app`: route entry của Expo Router; route nên là wrapper mỏng.
- `src/features/auth`: Auth & Account.
- `src/features/discovery`: Discovery & Commerce.
- `src/features/learning`: Learning Experience.
- `src/features/ai-engagement`: AI & Engagement.
- `src/shared`: component, API config, token và utility dùng chung.

Các thư mục module chưa có implementation chứa `.gitkeep` để Git theo dõi skeleton. Khi thêm code thật vào thư mục, có thể xóa `.gitkeep` tương ứng.
