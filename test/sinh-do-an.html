HOÀN TẤT

Hệ thống Quản lý Bệnh xá Thú Cưng (PetCare)

Đồ án thực chiến áp dụng mô hình MERN Stack (MongoDB, Express, React, Node.js).

1. Yêu cầu Chức năng (Features)

  • Xác thực và phân quyền (Admin, Bác sĩ, Khách hàng).
  • Quản lý lịch hẹn khám bệnh và theo dõi hồ sơ thú cưng.
  • Tích hợp giỏ hàng và thanh toán trực tuyến cho các sản phẩm phụ kiện.

2. Cấu trúc Database (MongoDB)

// Users Collection
{ _id, name, email, role: 'doctor' | 'customer', phone }

// Appointments Collection
{ _id, userId, petName, date, status, doctorId }

// Products Collection
{ _id, title, price, stock, category }
